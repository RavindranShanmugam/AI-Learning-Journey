## Basic Python Concepts

### Variables

Variables store information.

Example:

```python
name = "Ravi"
age = 30
```

---

### Print Statement

Used to display information.

Example:

```python
print("Hello World")
```

---

### Lists

Lists store multiple items.

Example:

```python
books = ["The Millionaire Next Door", "AI for Dummies"]
```

---

### Functions

Functions perform reusable tasks.

Example:

```python
def greet():
    print("Hello Ravi")
```
