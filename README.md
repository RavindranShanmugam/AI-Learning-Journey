# 🤖 AI Concepts

## What is Artificial Intelligence?

Artificial Intelligence (AI) is technology that enables computers to perform tasks that normally require human intelligence.

Examples:

* ChatGPT
* Claude
* Google Gemini
* AI Image Generation
* AI Voice Assistants

---

## What is an AI Agent?

An AI Agent is a system that can:

1. Receive a goal
2. Think about the task
3. Use tools
4. Take actions
5. Return results

Example:

User → "Analyze this document"

Agent →

* Reads document
* Extracts information
* Summarizes findings
* Returns output

# 🔗 LangChain Notes

## What is LangChain?

LangChain is a framework that helps developers build AI applications.

It allows AI models to:

* Access documents
* Use tools
* Remember conversations
* Search databases
* Work with external systems

### Simple Explanation

Think of ChatGPT as a brain.

LangChain helps connect that brain to:

* Files
* Websites
* Databases
* APIs

# 🦙 Ollama Notes

## What is Ollama?

Ollama allows large language models to run locally on your computer.

Benefits:

* Privacy
* No API costs
* Offline usage
* Fast experimentation

### Models I Want To Explore

* Llama
* Mistral
* Gemma
* Qwen

### Commands

Run a model:

```bash
ollama run llama3
```

List installed models:

```bash
ollama list
```
