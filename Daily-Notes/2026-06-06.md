## AI Concepts Learned

### What is an AI Agent?

An AI Agent is a system that can:

1. Receive a goal
2. Think through the task
3. Use tools when needed
4. Take actions
5. Return results

Example:

User → "Summarize this document"

Agent →

* Reads document
* Extracts information
* Creates summary
* Returns output
