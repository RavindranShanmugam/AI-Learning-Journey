# Local AI Chatbot

## Project Overview

This project is a simple AI chatbot that runs locally on my computer using Ollama.

The goal is to learn how AI models work and build a chatbot without paying API costs.

---

## Why I Built This

I want to:

* Learn Artificial Intelligence
* Understand Large Language Models (LLMs)
* Practice Python
* Explore AI Agents
* Build AI applications locally

---

## Technologies Used

### Ollama

Runs AI models locally on my computer.

## Setup Process

### Install Ollama

Download and install Ollama.

### Install a Model

Example:

```bash
ollama run llama3
```

### Verify Installation

```bash
ollama list
```
