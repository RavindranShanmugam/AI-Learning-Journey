# AI Agents Concepts

## What is an AI Agent?

An AI Agent is a system that can:

1. Receive a goal
2. Think about the task
3. Use tools when needed
4. Take actions
5. Return results

Unlike a normal chatbot, an AI Agent can perform tasks rather than simply answer questions.

---

# Simple Example

User:

"Find the latest AI news and summarize it."

Agent:

1. Searches the internet
2. Reads articles
3. Extracts key points
4. Creates a summary
5. Returns the result

---

# AI Agent vs Chatbot

## Chatbot

Input:

"What is AI?"

Output:

A text answer.

---

## AI Agent

Input:

"Research AI startups and create a report."

Output:

* Searches sources
* Collects information
* Organizes findings
* Generates report

---

# Core Components of an AI Agent

## Brain

The AI model.

Examples:

* GPT
* Claude
* Llama
* Mistral

---

## Memory

Stores information from previous interactions.

Allows the agent to remember context.

---

## Tools

Extra capabilities.

Examples:

* Calculator
* Web Search
* PDF Reader
* Database Query
* Email Sender

---

## Planning

Ability to break large goals into smaller tasks.

Example:

Goal:

"Analyze a company's finances."

Tasks:

1. Collect financial statements
2. Extract data
3. Calculate metrics
4. Generate report
