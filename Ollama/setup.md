# Ollama Setup Guide

## What is Ollama?

Ollama is a tool that allows Large Language Models (LLMs) to run locally on your computer.

Instead of paying for API calls, models can run directly on your machine.

Examples of models:

* Llama
* Mistral
* Gemma
* Qwen

# Installation

## Windows

1. Download Ollama from the official website.
2. Run the installer.
3. Restart the terminal if necessary.

---

# Verify Installation

Open Command Prompt or PowerShell and run:

```bash
ollama --version
```

If Ollama is installed correctly, the version number will appear.

---

# Running My First Model

Example:

```bash
ollama run llama3
```

This downloads and runs the model.

---

# Useful Commands

## List Installed Models

```bash
ollama list
```

---

## Show Running Models

```bash
ollama ps
```

---

## Remove a Model

```bash
ollama rm llama3
```

---

## Pull a New Model

```bash
ollama pull mistral
```
