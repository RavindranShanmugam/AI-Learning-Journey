# LangChain Basics

## What is LangChain?

LangChain is a framework that helps developers build applications powered by Large Language Models (LLMs).

It allows AI models to work with:

* Documents
* Databases
* APIs
* Memory
* External tools

---

## Simple Explanation

Think of ChatGPT as a brain.

LangChain helps connect that brain to the outside world.

Without LangChain:

AI can only answer based on what it already knows.

With LangChain:

AI can search files, access tools, read documents, and complete tasks.

---

## Why Use LangChain?

LangChain helps build:

* AI Chatbots
* AI Agents
* Document Question-Answer Systems
* Personal Assistants
* Knowledge Bases

---

## Important Components

### LLM

The AI model itself.

Examples:

* GPT
* Claude
* Llama
* Mistral

---

### Prompt

Instructions given to the AI.

Example:

"Summarize this document."

---

### Memory

Allows AI to remember previous conversation context.

---

### Tools

Extra abilities that AI can use.

Examples:

* Calculator
* Search Engine
* Database Query
* PDF Reader

---

### Agent

An AI system that can decide which tools to use and when to use them.

---

## LangChain + Ollama

LangChain can work with Ollama.

This allows local AI models to:

* Read documents
* Answer questions
* Build agents
* Run locally on a personal computer
